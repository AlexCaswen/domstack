# Privacy Policy for DOMstack

Effective date: August 22, 2026

DOMstack is a Chrome extension that automatically dismisses recognized subscription-flow
interruptions on Substack websites.

## Data collection

DOMstack does not collect, sell, transmit, or share personal information, browsing history, website
content, analytics, or usage data.

## Local page processing

DOMstack's bundled content script examines page elements on `*.substack.com` solely to identify and
dismiss supported prompts. This processing occurs locally in the user's browser. Page content is not
sent to the developer or any third party.

## Extension settings

DOMstack uses Chrome's synchronized storage to save one setting: whether the extension is enabled or
paused. Google may synchronize this setting between browsers signed in to the same Google account in
accordance with Google's privacy policy. DOMstack does not have access to the user's Google account
or synchronization credentials.

## Remote code and third-party services

DOMstack does not execute remotely hosted code and does not communicate with developer-operated or
third-party servers. It does not use advertising, analytics, tracking, or payment services.

## Limited Use

DOMstack's use of information received from Google APIs adheres to the Chrome Web Store User Data
Policy, including the Limited Use requirements.

## Data retention and deletion

The developer retains no user data. Users can remove the saved enabled-or-paused setting by
uninstalling the extension or clearing the extension's stored data through Chrome.

## Changes to this policy

Material changes to this policy will be published in this repository with an updated effective date.

## Contact
